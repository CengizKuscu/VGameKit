## GKLogging Reference

English reference for the GKLog logging utility.

## Overview
GKLog provides logging at various levels with color-coded output in Unity Console.

## Key Features
- Log at different LogState levels
- Compiled with GAMEKIT_LOG flag to enable logging
- Colorized output by log level

## Example
```csharp
GKLog.Log(LogState.Info, "An information message");
```

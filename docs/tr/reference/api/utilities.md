# Utilities Referans

Bu belge VGameKit Utilities modülünün Türkçe referansıdır.

## Genel Bakış / Overview
Utilities sınıfları, yardımcı uzantılar ve statik yardımcılar içerir.

## Örnek / Example
```csharp
public static class StringExtensions{ public static bool IsNullOrEmpty(this string s) => string.IsNullOrEmpty(s); }
```
